# anchor

Плагин Claude Code: **одна тема — одна вкладка, один worktree, один якорь**.

Параллельные сессии перестают драться за файлы, а состояние перестаёт жить в
контексте сессии. Тема крепится к якорю в [beads](https://github.com/steveyegge/beads)
— эпику или задаче; ветка, worktree и вкладка [herdr](https://herdr.dev)
производны от него.

## Зачем

За один день работы в четыре параллельные сессии: `main` трижды уехал под
руками, две ветки пришлось сводить вручную, merge подсунул устаревшую версию
чужого теста. В трекере 268 задач и ни одного места, отвечающего на вопрос
«что сейчас в работе».

Причина не в числе окон, а в том, что состояние помнит только процесс. Когда
помнит трекер, число окон перестаёт иметь значение.

Подробный разбор решений и их причин — в [DECISIONS.md](DECISIONS.md).

## Что внутри

| Что | Где | Делает |
|---|---|---|
| Хук старта сессии | `hooks/anchor-session-start.sh` | Определяет якорь по имени ветки, переименовывает вкладку herdr в заголовок якоря (только в worktree), печатает, что в теме открыто |
| `/anchor` | `commands/anchor.md` | Начать тему или вернуться в неё: якорь, ветка, worktree, окружение |
| `/anchor-done` | `commands/anchor-done.md` | Свести в main, убрать worktree, ветку и вкладку, закрыть якорь |
| Скилл `anchor` | `skills/anchor/SKILL.md` | Как работать по схеме, включая работу с dispatch и соседними сессиями |
| Очередь тяжёлых команд | `scripts/heavy` | `heavy <команда>`: тесты и сборка воркеров по очереди, не больше `HEAVY_SLOTS` разом (по умолчанию 1) |

## Чего он требует

- **beads** (`bd`) — трекер, где живут якоря. База лежит в основном дереве
  репозитория; хук умеет находить её из worktree.
- **herdr** — менеджер вкладок и worktree. Без него хук просто не переименует
  вкладку: остальное работает.
- **git worktree** — изоляция тем.
- Имя ветки должно содержать id якоря: `feature/aio-ppku-jobs-queue` → `aio-ppku`.
  Если имена ветвей диктует трекер компании, хватит кода в заголовке якоря:
  ветка `AS-2103-doctype-provenance` найдёт якорь «AS-2103: …». Несколько кодов
  читаются от частного к общему: `AS-1637-GXP-036-gxp-validator` найдёт якорь
  «GXP-036: …», а не эпик «AS-1637».

Всё необязательное отсутствует тихо: нет herdr — нет переименования; нет beads —
хук молчит и выходит с нулём. Хук, ломающий старт сессии, будет снесён в первый
же плохой день, и правильно.

## Установка

```bash
git clone <этот-репозиторий> ~/.claude/plugins/anchor
```

Затем подключить плагин в Claude Code (`/plugin`) и перезапустить сессию.

## Границы

- **Схема личная.** `.beads` не версионируется и виден только на своей машине;
  для общего трекера нужна другая механика.
- **Два трекера не синхронизируются.** Ссылка из якоря на проект в CRM — и всё.
- **Изоляция на уровне каталога.** Две сессии в одном worktree вернут гонки.
- Проверено на macOS с Apple Terminal, `sh` (не bash-измы), beads 0.62 и herdr
  с socket API. На других связках не проверялось.
